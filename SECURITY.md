# Security Policy

## Supported Scope

This repository is the parent platform codebase. Security reports may include:

- Authentication/session handling
- Route protection and middleware behavior
- Data exposure through public APIs/pages
- Dependency vulnerabilities

## Reporting a Vulnerability

Please do not open public issues for vulnerabilities.

Report privately with:

- Affected path(s)
- Reproduction steps
- Expected vs actual behavior
- Risk/impact summary

Preferred contact: `security@docheng.com`

## Response Targets

- Initial triage: within 3 business days
- Status update cadence: at least weekly until resolved
